# IRON-EDGE / 钢锋

基于 MFPS 2.0 的多人 FPS 试玩版（Windows x64，Unity 6000.3.24f1 + Built-in 管线）。

## 下载

到 [Releases](../../releases) 下载 `IRON-EDGE-win64.zip`，解压后双击 `启动游戏.bat`（第一次会请求管理员权限以放行联机用的防火墙端口），或直接运行 `IE_Shim.exe`。

## 玩法

- 大厅：右下「开始游戏」进创建房间，或「加入房间」走房间列表；同一局域网可直接联机
- 操作：WASD 移动、鼠标视角、左键开火、右键瞄准、R 换弹、F 交互、Esc 暂停、Tab 计分板
- 地图：时空错乱—庄园/战场（左古欧庄园、右荒芜沙滩，开局空降 + 5 秒出生保护）
